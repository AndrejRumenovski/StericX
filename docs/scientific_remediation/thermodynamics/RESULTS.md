# Thermodynamics and kinetics remediation results

The scoped corrections below pass the retained numerical witnesses and focused
regression tests. This does **not** establish complete conformer sampling,
free-energy accuracy, or a physical catalytic rate model. The original C01–C21
classifications and all original audit files remain unchanged. See `LEDGER.md`
for the evidence and decisions recorded before code changes.

## Retained conventions and limits

C08 remains an explicit MMFF policy: status 1 means the iteration limit was
reached and is retained; negative statuses/nonfinite energies are excluded. The
code and report no longer call every retained geometry converged. Eleven original
MMFF fixtures retain this policy and independently verify their conditional
force-field-energy populations. No experimental free-energy validation follows.

C13 remains an explicit uniform fallback when weights are absent, even when
energy metadata is supplied. Supplied weights are not automatically established
as Boltzmann probabilities. Zero-weight conformers still contribute to ensemble
extrema and counts. Serialization of a normalized audit probability to f32 can
round a tiny value to zero; that rounded observation is not fed back into
aggregation. Common scaling is tested on representable inputs; decimal parsing
and final f32 descriptors retain their ordinary rounding limits.

CREST reweighting uses the precision of the printed individual energies and
requires complete groups. Group degeneracy is not assumed to imply equal
rotamer energies. Electronic-energy populations omit conformational entropy.
The new `temperature_checked_rotamer_populations_v2` cache-policy key prevents
reuse of old population caches, and unverified combined legacy caches are no
longer promoted. External CREST execution itself was mocked for command/cache
regressions; this work does not assert external sampling correctness.

Unsigned ee does not identify an absolute enantiomer. Ni-hDA ID 2064 retains the
unresolved source ee/ddG inconsistency; neither its target nor its source ee was
silently changed. Correct reaction temperature metadata does not imply that
historical conformer weights were calculated at that temperature.

## Measured results and reproducibility

The complete scoped replay is retained at
`.stericx/scientific_remediation/thermodynamics/witness_replay_v3/`.
Its `manifest.json` SHA-256 is
`e8d34dc38d576e9aefc7eef58343b5297b8767d59457656a3a3d22571ae342d2`.
It contains copied executables/Python source, raw stdout/stderr, native packed
outputs, 744 Decimal scalar kinetic comparisons, 51 aggregate scalar/rejection
comparisons, 14 CLI runs, 6 CREST cases, 11 MMFF cases, and 24 ee cases. The
manifest binds those artifacts and the unchanged historical evidence manifest.
Nine kinetic cases are invalid or have exponents outside the bounded Decimal
comparison; focused checked-API tests separately cover extreme finite inputs.

The maximum relative error over representable normal rates decreased from
6.92313e-8 to 5.29218e-8. Maximum ee absolute error is 3.69286e-6 percentage points.
Changes are intentional corrections, not bitwise equivalence: 13 rate, 57 ee,
38 R-percentage and 67 S-percentage f32 observations changed across the original
grid. Finite selectivity changes are at most 7.62940e-6 percentage points.
`measured_deltas.json` retains the counts and exact measured deltas. Finite f32
rates can still underflow or overflow; callers can select the checked/log API.

Thirty-nine initial focused tests passed: existing kinetics (6), kinetics/CLI remediation
(4), reaction (4), buried-volume aggregation remediation (3), Python
thermodynamics (10), and quantum backend (12). Commands, complete logs and host
versions are retained at
`.stericx/scientific_remediation/thermodynamics/focused_checks_v1/`.
Ruff passes for the changed Python implementation, tests and replay helper;

The first final discovery attempt is retained as a failure. A new convergence
test module imported pytest in the general environment and used seven module-level
functions that unittest would not discover. The repair converts the same seven
assertion bodies into discoverable unittest methods, declares the reference
environment requirement, and runs every method there. It changes test integration,
not scientific assertions or production calculations. The original
[failed receipt](receipts/failed_final_checks_v1.json), logs and separate
[repair evidence](../resolution_analysis/test_integration_v1/receipt.json) remain
available. The earlier engineering discovery of 143 tests predates that module.

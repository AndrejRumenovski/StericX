# C3 row rejection: evidence package preparation

**IN PROGRESS.** Native measurements and the independent review are being
closed. This directory is reserved for rejected-C3 evidence; publication has not
yet been assembled, verified or restored. The final accepted executable and its
fresh scientific replay will be published separately under `final_optimization`.

The required closure retains all **972 native launches**: 720 over the full
40 configurations and 252 incremental launches over 14 configurations, totaling
432 measured pairs and 108 warmup processes. Every raw result, including slower
samples, belongs in this package. Reduced predicate counts are diagnostic work
counts and do not establish a wall-time improvement.

C3's scoped scientific equivalence evidence remains distinct from its performance
decision: 13 lanes/128,021 observations, 25 independent-reference stages, four
93-case CLI captures, 24 additional CLI cases, 31 additive command-boundary cases,
and eight million-prediction f32 streams. Source/build/engineering evidence,
30168-frame operation probes, source review, rejected patch, failed tooling
attempts and the timestamp-only reference resolution remain retained.

Assembly will require the sealed rejection and exact accepted-C2 restoration
receipts. It will reuse immutable C1/C1b/C2 payloads by pinned file/chunk identity,
preserve original bytes and absolute JSON strings, and exclude executables,
disposable targets, virtual environments and external directory links. Only
actually executed helper dependencies will be frozen. This preparation note is
not a completed package or a new scientific/performance acceptance claim.
